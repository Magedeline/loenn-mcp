loenn-mcp v5.3.1
================

Fix MdMC tile generator producing hollow rooms.


WHAT'S NEW IN v5.3.1
---------------------

PCGHelper:
  - Fixed mdmc_generate filling the tile grid in a fixed top-left-to-
    bottom-right raster order regardless of which neighbour offsets a
    configuration used. Every preset in MDMC_PRESETS includes at least
    one "future" neighbour (East and/or South) relative to that scan
    order, so those cells were always still-air when read, collapsing
    the n-gram context to essentially "0,0" almost everywhere and
    generating near-empty rooms (solid border, zero interior) regardless
    of training data. Added _causal_scan_dirs(), which picks a per-axis
    raster direction that maximises how many of a preset's offsets are
    already generated by the time each cell is visited. The default E+S
    preset is now fully causal (was 0%); mixed presets improve from
    ~25% to ~75% causal.
  - Fixed pcg_markov_fill (the MCP tool wrapper) never passing
    is_start/is_end through to place_entities, so no room filled via
    that tool ever received a player spawn or golden berry. Added
    start_room / end_room parameters.


loenn-mcp v5.3.0
================

Audio-event reach fixes, PCGHelper bug-fix sync, and a verified fastmcp bump.


WHAT'S NEW IN v5.3.0
--------------------

Audio events:
  - New tool: replace_audio_event(map_path, old_event, new_event, dry_run).
    get_map_metadata / set_map_metadata only ever reached the meta element's
    own attributes, and update_room only touches one room at a time — so
    renaming an FMOD event (e.g. a namespace rename like "pusheen" -> "DZ")
    meant editing rooms one by one and missing anything nested. This walks
    the entire tree in one call: map metadata (including nested elements),
    every room, and any entity/trigger carrying its own audio override
    (lightningBlock, PowerGenerator, etc).
  - Fixed: get_map_metadata / set_map_metadata could not read or write
    settings nested below meta (e.g. meta -> mode -> audiostate -> Music,
    AltMusic, AmbienceProgress — the per-side audio overrides shown in
    Lönn's "Map Metadata" dialog). get_map_metadata now recurses to any
    depth instead of stopping one level in; set_map_metadata takes an
    optional `subpath` (e.g. "mode/audiostate") to target nested elements,
    creating missing intermediate elements as needed.

PCGHelper sync (from Maggy-Studio/PCGHelper's decal/entity-placement fix):
  - Golden berries are now emitted as "strawberry" entities with
    golden=True, matching the real vanilla entity — the Python port was
    still emitting a nonexistent "goldenBerry" entity type in
    pcg_helper.place_entities, pcg_helper.run_pipeline, and
    pcg.generate_room_from_pattern (where it also meant the "reuse golden
    berries from the reference room" heuristic could never trigger, since
    reference rooms are counted by their real entity name).
  - Decal texture catalog replaced with real vanilla paths
    (decals/generic/*, particles/*) — the previous scenery/* paths don't
    exist in the graphics dump and rendered nothing. Added
    resolve_decal_texture() to validate/fall back safely.
  - Decal and CameraTargetTrigger placement now clamp to room bounds
    instead of occasionally landing outside the room.
  - Added default attributes for strawberry/spikes/spring entities and
    CameraTargetTrigger so generated rooms don't ship with missing fields.

Dependencies:
  - Bumped minimum fastmcp from 3.0.0 to 3.4.0 (verified against the latest
    3.4.4). No API changes affected this project between 3.2.x and 3.4.x.


loenn-mcp v5.2.0
================

PCGHelper integration — full Python port of the PCGHelper Lönn mod algorithms
for MdMC/WFC tile generation, skeleton layout, and the end-to-end PCG pipeline.


WHAT'S NEW IN v5.2.0
--------------------

5 new MCP tools (87 tools total):

  pcg_mdmc_presets        — list all 7 MdMC configuration matrix presets with
                            descriptions (L-shape, 4-neighbour, cross, full, …)

  pcg_skeleton_generate   — lay out a non-overlapping room skeleton connected
                            edge-to-edge (ported from CelesteSkeletonScript).
                            First room = START (player spawn), furthest room =
                            END (golden berry). Writes empty bordered rooms to
                            an existing .bin file. Run pcg_markov_fill next to
                            fill the tiles.

  pcg_markov_fill         — fill rooms with tiles using MdMC, WFC, or hybrid
                            mode (ported from MarkovLevelGenScript).
                            Supports: tile-level backtracking, cleanup passes,
                            auto-tiling, BG generation, playability repair,
                            interestingness/difficulty gating, entity placement,
                            smart decal & trigger placement.

  pcg_score_room          — evaluate a room's interestingness I and difficulty D
                            using the paper §4.2/§4.3 metrics:
                              I = w1·global_NLE + w2·local_NLE + w3·entropy
                              D = z1·hole_freq  + z2·local_LE  + z3·NLE_scarcity

  pcg_pipeline            — end-to-end one-shot generator (ported from
                            CelestePCGPipelineScript): skeleton layout → MdMC/
                            WFC/hybrid tile fill → cleanup → playability repair
                            → entity/decal/trigger placement → exit carving.
                            All parameters are tunable.

New module: loenn_mcp/pcg_helper.py
  - LcgRng: 32-bit LCG RNG mirroring Lua / C# System.Random subset
  - parse_config: 9-char MdMC matrix parser (7 built-in presets)
  - train_mdmc / mdmc_generate: MdMC with tile-level backtracking
  - train_adjacency / wfc_generate: WFC with entropy-based cell selection
  - generate_skeleton: non-overlapping room layout with adjacency graph
  - carve_exits: 3-tile-wide doorways between adjacent rooms
  - platformer_repair: BFS reachability + corridor carving
  - score_interestingness / score_difficulty: paper §4.2 / §4.3 metrics
  - generate_pattern_room: marioGen-v2 pattern-mode generation
  - place_entities / place_decals / place_triggers: smart spatial placement
  - run_pipeline: full end-to-end generation pipeline

No new runtime dependencies — stdlib only.

Source mod: PCGHelper (D:/Celeste/celeste/Mods/PCGHelper)
  Lua scripts by the PCGHelper mod author, ported to Python for MCP use.

loenn-mcp v3.0.1
================

Patch release: drop unused pygame + pytmx dependencies.

These were added by an earlier PR but never imported anywhere in the
package. They blocked installation on Pythons that don't have prebuilt
pygame wheels (e.g. Windows + Python 3.14), where pip would fall back to
building pygame from source and fail with:

    ModuleNotFoundError: No module named
    'setuptools._distutils.msvccompiler'

After this release, `pip install loenn-mcp` only pulls in `fastmcp`.

loenn-mcp v3.0.0
================

Closes the styleground / trigger gap reported by users — previously you could
add entities and rooms via MCP, but stylegrounds and triggers required opening
Lönn manually. Now everything is reachable from the agent.


WHAT'S NEW IN v3.0
------------------

6 new MCP tools (28 tools total):

  Triggers (room-level, mirror add_entity / remove_entity):
    add_trigger             — place a trigger in a room with width/height
                              and optional path nodes; auto-assigns a unique
                              ID across both entities and triggers.
    remove_trigger          — delete a trigger by ID.

  Stylegrounds (map-level, under Style/Foregrounds and Style/Backgrounds):
    list_stylegrounds       — numbered listing of FG + BG effects (and the
                              children of any `apply` groups).
    add_styleground         — add a parallax, custom Lua effect (e.g.
                              2.5DHelper/VoidBg), or an `apply` group to FG
                              or BG. Auto-creates Style/Foregrounds/
                              Backgrounds if missing.
    remove_styleground      — remove an effect by index.
    update_styleground      — merge property changes into an existing effect
                              (set keys, or pass null to clear them).

No new runtime dependencies.

loenn-mcp v2.0.0
================

Celeste map editor for AI agents — now with procedural generation, seeded
randomness strategies, pattern library extraction, and GameBanana map
ingestion.


WHAT'S NEW IN v2.0
------------------

4 new generation MCP tools (22 tools total):

  build_pattern_library   — scan local .bin maps and extract room patterns
                            into a reusable JSON library (PCG/patterns.json)

  generate_room_from_pattern
                          — generate a new room using patterns from the
                            library with a chosen strategy and seed.
                            Strategies: balanced, exploration, challenge,
                            speedrun.
                            Model profiles: creative, deterministic,
                            architect.

  validate_room           — check a room for playability problems (missing
                            spawn, no floor, entity out-of-bounds, etc.)

  ingest_external_map     — download maps from external URLs (.bin, .zip, or
                            GameBanana mod pages), extract patterns into the
                            library, and store attribution metadata.
                            Requires confirm_download=True as an explicit
                            opt-in; attribution string is recommended.

New module:  loenn_mcp/pcg.py
  - Room pattern extraction (size class, entity density, tile motifs, tags)
  - Pattern library load/save/merge (JSON, deduplicated by SHA-1 hash)
  - Seeded random.Random generation (reproducible with seed + profile)
  - Strategy-based tile grid and entity generation
  - Room validation helper (validate_room_structure)

No new runtime dependencies — stdlib only (urllib, zipfile, hashlib, json).

-------

loenn-mcp v1.0.0
================

Celeste map editor for AI agents — read, edit, analyze, and preview Celeste
.bin map files directly from GitHub Copilot, Claude Desktop, or any MCP
client. No Loenn installation required.


INSTALL
-------
  pip install loenn-mcp


WHAT'S INCLUDED
---------------
- 18 MCP tools across 5 categories:
    Map Reading    — list_maps, read_map_overview, read_room, get_room_tiles
    Map Editing    — add_entity, remove_entity, set_room_tiles, add_room,
                     remove_room, create_map
    Entity Catalog — list_entity_definitions, get_entity_definition,
                     list_trigger_definitions, list_effect_definitions
    Analysis       — analyze_map, visualize_map_layout, preview_map_section
    Rendering      — render_map_html (interactive HTML, zoom/pan/search)

- celeste_bin.py — pure-Python .bin parser, full read/write round-trip
                   (no Loenn or Everest required)

- preview_map.py — one-command HTML map preview that opens in the browser

- Works with maps created by Loenn or Ahorn
